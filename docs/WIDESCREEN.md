## 선택 사항: PCSX2 16:9 와이드 패치

추가 첨부 파일: **`SLPM-55158_177876CE.pnach`**. 한글패치 v1.0의 실행 파일 CRC **177876CE** 전용입니다. 일본어 원본 ISO에는 이 파일을 사용하지 마세요.

1. 먼저 위 xdelta 한글패치를 원본 ISO에 적용합니다. 이미 한글판 v1.0을 사용 중이면 다시 적용할 필요가 없습니다.
2. 이 릴리즈에서 `SLPM-55158_177876CE.pnach`를 다운로드합니다. 파일명과 `.pnach` 확장자를 유지하세요(`.pnach.txt`가 되지 않도록 주의).
3. **현재 사용 중인 PCSX2 데이터 폴더의 `patches` 폴더**에 넣습니다. 일반적인 Windows 설치 경로는 `%USERPROFILE%\Documents\PCSX2\patches`입니다. 포터블 설치나 사용자 지정 경로를 쓰는 경우 PCSX2의 **설정 → 폴더**에서 실제 패치 폴더를 확인하세요. `cheats`나 ISO 폴더에 넣는 파일이 아닙니다.
4. PCSX2 게임 목록에서 **한글판 게임 우클릭 → 속성 → 패치 → `Widescreen 16:9`**를 켭니다. 목록이 갱신되지 않으면 PCSX2를 재시작하고 다시 확인하세요.
5. 게임별 **그래픽 → 화면/디스플레이 → 화면비**를 **16:9**로 설정합니다. 패치의 `gsaspectratio=16:9`도 화면비를 지정하지만, 수동 화면비 설정을 사용하는 경우 16:9로 맞추세요.
6. 실행 중인 게임을 종료하고 **ISO에서 새로 부팅**하세요. 이전 세이브스테이트를 불러오는 대신 게임 내 메모리카드 저장을 사용하세요.

해제: `Widescreen 16:9`를 끄고 화면비를 자동 또는 4:3으로 되돌린 뒤 새로 부팅합니다. ISO 자체를 수정하는 패치가 아니므로 ISO를 다시 만들 필요는 없습니다.

적용되지 않을 때는 실제 패치 폴더, 파일 확장자, 게임 CRC `177876CE`, 패치 체크 상태를 확인하세요. **화면비만 16:9로 바꾸는 것은 카메라 와이드 코드 적용과 다릅니다.** 다른 빌드에서 CRC가 달라지면 파일명을 임의로 바꾸지 말고 해당 릴리즈에 동봉된 파일을 사용하세요.

원본 코드: **99skull**, [PCSX2 공식 패치 모음](https://github.com/PCSX2/pcsx2_patches/blob/main/patches/SLPM-55158_1429EB9F.pnach). 카메라 명령 4곳이 원본과 한글판에서 동일함을 정적으로 검증했습니다. **실제 경기 화면에서의 와이드 동작 검증은 아직 하지 않았습니다.** 2D 메뉴·HUD·동영상의 비율을 별도로 보정하는 코드는 포함되지 않습니다.

앞으로 새 한글패치 릴리즈에도 해당 빌드와 호환되는 와이드 `.pnach` 파일을 함께 첨부합니다.
